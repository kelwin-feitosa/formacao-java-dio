# ☕ Formação Java Developer - DIO

Este repositório centraliza os desafios técnicos e laboratórios desenvolvidos durante o Bootcamp da **DIO**. Cada diretório representa um exercício independente focado na prática de conceitos específicos da linguagem Java.

## 🗂️ Exercícios e Desafios de Prática

Abaixo estão os módulos realizados, organizados por competência técnica:

### 🔹 Estruturas de Dados (Collections API) 
* **[Módulo: List](src/collections/list):** Implementação completa de desafios envolvendo a interface `List`.
  * **Operações Básicas:** Manipulação de carrinhos de compras e listas de tarefas.
  * **Pesquisa:** Algoritmos de busca em catálogos de livros e análise de números.
  * **Ordenação:** Uso avançado de `Comparable` e `Comparator` para organização de objetos complexos.

### 🔹 Sintaxe e Lógica (Fundamentos)
* **[Conta Banco](src/sintaxe):** Prática de entrada/saída de dados e manipulação de tipos primitivos via terminal.
* **[Controle de Fluxo](src/controlefluxo):** Exercício focado em estruturas de repetição e **Tratamento de Exceções Customizadas**.

## 🧠 Conceitos Consolidados
* **Lógica de Programação:** Estruturas condicionais, laços de repetição e tipos primitivos.
* **POO:** Encapsulamento, construtores, métodos e separação de responsabilidades.
* **Collections:** Diferença entre `Collection` e `Collections`, além de algoritmos de ordenação (`Comparable`/`Comparator`) e busca.

## 🛠️ Stack Utilizada
* **Linguagem:** Java 21 (visto no seu terminal!)
* **IDE:** VS Code / IntelliJ (no Pop!_OS)
* **Ferramentas:** Git para versionamento e SDKMAN para gestão de versões do JDK.
