# 🔍 Módulo: Pesquisa em List

Este diretório contém exercícios práticos focados em algoritmos de busca e filtragem de dados dentro de coleções `List`.

## 🛠️ Atividades Desenvolvidas

### 1. Catálogo de Livros
Sistema de busca de livros com diferentes critérios.
- **Destaques:** 
  - Uso de `List` temporária para retornar múltiplos resultados (Busca por Autor e Ano).
  - Uso de `break` para otimizar a busca por título (retornando apenas o primeiro).
  - Manipulação de múltiplos atributos (`String`, `int`).

### 2. Soma de Números
Operações matemáticas e busca de extremos em uma lista de inteiros.
- **Destaques:**
  - Algoritmo de busca de **Maior** e **Menor** valor.
  - Uso da classe Wrapper `Integer`.
  - Validação de lista vazia para evitar erros de execução.

---

## 🧠 Conceitos de Pesquisa Praticados:
- **Filtragem:** Percorrer a lista com `for-each` e selecionar itens via `if`.
- **Operadores Lógicos:** Uso de `&&` para intervalos de valores.
- **Retornos Estruturados:** Diferença entre retornar uma lista vazia `[]` ou um objeto `null`.
