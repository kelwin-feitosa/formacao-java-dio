# 📦 Módulo: Operações Básicas com List

Este diretório contém exercícios práticos para fixação dos conceitos de manipulação de coleções em Java, utilizando a interface `List`.

## 🛠️ Atividades Desenvolvidas

### 1. Lista de Tarefas
Um sistema simples para gerenciar descrições de atividades.
- **Conceitos:** `ArrayList`, adição e remoção de objetos.
- **Destaque:** Implementação de lógica para remover múltiplas ocorrências de uma mesma tarefa e sobrescrita do método `toString()`.

### 2. Carrinho de Compras
Um sistema de e-commerce simplificado para gerenciar itens de um pedido.
- **Conceitos:** Cálculos matemáticos integrados à coleção, manipulação de atributos `double` e `int`.
- **Destaque:** Desenvolvimento de método para iterar sobre a lista e calcular o valor total (Preço x Quantidade) de todos os itens.

---

## 🧠 O que pratiquei aqui:
- **Tipagem com Generics:** `List<Tarefa>` e `List<Item>`.
- **Iteração:** Uso de loops `for-each` para percorrer e processar dados.
- **Métodos da List:** `add()`, `remove()`, `removeAll()`, `size()` e `isEmpty()`.
